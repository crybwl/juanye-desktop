# 卷页 v0.5.0-beta.3 · 题册排版预览版

这是 Windows 10/11 x64 的公开预发行版。当前稳定版不受影响。

## 下载

- `Juanye-0.5.0-beta.3-Setup.exe`：安装版，可选择安装目录。
- `Juanye-0.5.0-beta.3-x64.zip`：免安装版，完整解压后运行 `卷页.exe`。
- `SHA256SUMS.txt`：两个下载包的 SHA-256 校验值。

安装包未做商业代码签名，Windows 可能提示未知发布者。

## 本次更新

- **题册分栏**：一章可混排单栏、双栏和三栏，支持设置栏距、分隔线和手动换栏，长段落和表格可跨栏续排。
- **选项自动排布**：按文字、公式实际宽度和题图剩余空间自动排成 4、2 或 1 列，可设置全书默认，也可单题覆盖。
- **版式后端**：预览和 PDF 已能渲染跨栏标题、空白/横线/方格/坐标纸作答区、自定义块样式与按章、节或全书重置的独立计数器；这些能力尚无独立操作面板。
- **自上次公开版以来**：独立本地题库、试卷分析、Word 导出、独立教辅书稿、项目备份及既有动效优化也随此版提供。完整记录见 [CHANGELOG](https://github.com/crybwl/juanye-desktop/blob/v0.5.0-beta.3/CHANGELOG.md)。

## 兼容性

新版可读取旧书稿；使用新节点或样式时，书稿会保存为 v2。旧程序无法打开 v2 书稿。升级或回退前，建议导出书稿、试卷项目和题库备份。测试版导出正式材料前请先检查预览，尤其是长表格、窄栏和大幅题图。
