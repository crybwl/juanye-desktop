# 卷页 v0.3.2

卷页的首个公开发布版本：Windows x64 本地试卷编辑、公式排版和可选图片 OCR。

## 下载

- `Juanye-0.3.2-Setup.exe`：安装版，可选择安装目录。
- `Juanye-0.3.2-x64.zip`：免安装版，完整解压后运行 `卷页.exe`，不要只取出 EXE。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。

适用于 Windows 10/11 x64。安装包尚未购买商业代码签名证书，Windows 可能提示未知发布者；请从本仓库下载并核对校验值。

## 主要功能

- 多题型编辑、大题管理、拖动排序、批量属性、撤销重做及历史记录。
- 图片/PDF OCR、原图核对与重新识别；模型服务和 API Key 由使用者自行配置。
- 题目文件、独立解析和解析版试卷导入，答案与解析进入对应的可编辑字段。
- 内置 KaTeX 公式、Markdown 表格和受限 TikZ/WASM 绘图，无需额外安装 LaTeX 即可预览与导出 PDF。
- 普通试卷、独立答题卡、一体卷，以及独立可调的答题空间。
- PDF、Markdown、LaTeX 源码及 `.juanye` 项目导出。
- 深色、淡色、Telegram 风格主题及完整动效。

## 0.3.2 优化

- 预览缩放不再逐帧触发整卷 React 渲染；屏外页面绘制隔离，滚动页码不扫描全部页面。
- 复用分页测量和复杂长题边界，整段与公式采用有界 LRU 缓存。
- 保留面板弹簧、页面入场、缩放及背景动效；修复连续导出时提示浮层混入 PDF 的问题。

本机同环境压力样例包含 120 题、44 页、1400 个公式和 20 个表格，切换预览的长任务累计耗时约从 1111ms 降至 52ms。该结果不代表所有设备的固定性能或帧率。

## 使用提醒

- 日常编辑与 PDF 排版在本地进行；主动运行远程 OCR 时，图片和指令会发送给所配置的服务，可能产生费用。
- OCR 和文档转换结果需要人工校对；复杂 Word 公式、PDF 分栏或扫描内容不保证无损恢复。
- 草稿与模型配置沿用本机存储，API Key 不随项目和导出文件转移。
- 答题卡是可打印填写版，不承诺兼容特定机读设备。
