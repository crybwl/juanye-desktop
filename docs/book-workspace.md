# 教辅编辑台（0.5.0-beta.1）

顶部“教辅编辑台”进入独立书稿。采用连续文档流，不是任意绝对定位的画布；修改一处后后文自然续排，适合讲义、题册与章节练习。

## 使用

1. 左侧填写书名、作者，添加封面、前言或章节；章节可拖动排序，也可用上移/下移按钮。
2. 中间直接输入正文，用工具栏添加标题、知识讲解、例题、练习、公式、表格、图片或手动分页。公式可用工具栏输入，双击公式再编辑；输入完整 `$…$` 可转换为行内公式。
3. “从题库插入”支持批量选择和目标章节；也可复制当前试卷。书稿使用独立题目快照，题干、选项、答案、解析、图片和绘图都能编辑，不回写题库原题。带 ABCD 标记的题干粘贴可分配到选项字段。
4. 右侧“排版”控制 A4/A5/B5、装订侧边距、字号、行段距、题距、编号和答案位置；目录读取章节/正文标题并计算实际页码。预览默认仅当前章，“全书预览”生成当时的整书快照。
5. “导出整本 PDF”使用独立本机渲染窗口，可取消。另用“导出项目”保存 `.juanye-book`，在其他电脑“打开项目”后仍可编辑。

`Ctrl+S` 保存书稿，`Ctrl+E` 导出教辅 PDF。旧组卷与题库仍为原入口，不改动原有工作流。

## 数据与性能边界

- 自动保存与上一版备份位于独立 `book-draft.json`；手动版本与旧试卷历史分开。手动版本最多 20 份，满时明确拒绝新增，不偷偷删除旧版本。损坏草稿不会被空白书稿静默覆盖。
- 项目 ZIP 为 `manifest.json`、`project.json` 和哈希去重附件；校验协议、尺寸、路径、图片及内容哈希，不执行导入的 HTML、脚本或外部资源。项目不含密钥。
- 编辑器只挂载当前章。题目 NodeView 按题订阅，未编辑的题目不挂载整套字段控件；非活动工作区暂停预览请求。完整分页按需运行，不在每次按键后重新生成整本书。原有动效不删除。
- 分页时按 1:1 几何测量，完成后才做屏幕缩放/离屏绘制优化；打印恢复全部页面。长表格在分片测量前重复表头，超页题干与解析允许续页。
- 为重复句子增加稳定文本身份与续接偏移校正。导出前逐文本片段检查缺失/重复，失败会明确报错，不保存不完整文件。实际 PDF 还需检查物理页面，不能仅凭 DOM 声称无裁切。
- 当前是首版测试功能，不含教辅 Word 导出、任意位置文本框、脚注/索引、跨章交叉引用、协同编辑或书稿多项目管理中心。原试卷 Word 导出保留。
- 字体优先使用当前电脑已有中文字体，缺少时明确提示后备字体；KaTeX、分页和受限 TikZ 随应用内置，无需另装 TeX。排版时不调用模型或网络。

## 开源考察与采用

本轮先阅读官方仓库、实现与许可证，再落地。star 是筛选线索，不作为可靠性保证。

- [Tiptap / ProseMirror](https://github.com/ueberdosis/tiptap)：采用 MIT 开源基础的结构化文档、事务、选区与表格扩展；本轮查询约 3.9 万 star。未使用收费 Pages 或云服务，也未强行降级现有 KaTeX 以安装数学扩展；公式为本地自定义节点。
- [Paged.js](https://github.com/pagedjs/pagedjs)：采用 MIT 的细分排版实现（本轮约 1,500 star），复用打印 CSS、目录 target-counter 和分页钩子。锁定 0.4.3 并进行实际长书稿验收，不把上游库“返回成功”等同于完整排版。
- [重复文字的上游问题 #208](https://github.com/pagedjs/pagedjs/issues/208) 与本地 `createBreakToken/indexOfTextNode` 源码：重复兄弟文本和续页字符串首匹配会回跳。本项目不改 `node_modules`，在自己的投影/分页钩子中隔离文本身份、按后缀位置续接，并加完整性门槛。
- [Electron webContents 文档](https://www.electronjs.org/docs/latest/api/web-contents)：按 Electron 45 的实际接口，以英寸提供自定义打印尺寸；文件采用临时写入后替换，错误和取消保护既有文件。

详见 `THIRD_PARTY_NOTICES.md` 和 `docs/teacher-workflows-validation.md`。千题样稿的实际页数、资源和检查结果以回归报告为准，不承诺任意内容都落在固定页数，也不把屏幕外自动化耗时当作用户机器 FPS。
