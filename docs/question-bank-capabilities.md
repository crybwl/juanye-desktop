# 完备本地题库的功能边界与路线图

更新于2026-10-28。下面区分“应该具备”和卷页当前已有的基础，未实现的规划不是本轮交付承诺。优先做可靠的本地工具，不以强制联网、付费AI或协作平台替代基本编辑与数据安全。

## 一、完整题目模型

- 独立保存题干、选项、答案、解析、评分点、解题步骤、图表/几何图/附件；支持单选、多选、填空、判断、解答、材料子题及自定义题型。
- 稳定题目ID、逻辑题目与修订ID分离；来源、原题号、版权/授权信息、年级、教材、章节、年度、地区、考试类型、适用学段与预计用时。
- 知识点允许多标签和上下级关系；难度标注、AI估计、真实作答统计必须分开，不把“看起来难”当成测量结果。

当前已有题干/选项/答案/解析/图表/TikZ/主要属性、稳定ID和修订；教材树、完整来源结构、评分点及材料子题关系仍需体系化。

## 二、导入与质量核对

- 图片/剪贴板/OCR、PDF、Word、文本/Markdown、结构化备份等多种入口；识别与导入先核对再入库，失败项目可单独重试。
- 字段映射到真实可编辑的题干、选项、答案、解析，不把HTML、JSON或整页识别结果塞入题干。
- 按稳定ID及规范化内容判重；相似题提供候选比较而非直接删掉。导入更新需明确选择，保护本地编辑和卷内快照。
- 发现缺答案、残缺选项、公式异常、题图缺失、答案越界、总分冲突等问题；原图并排对照，批量修复必须可预览和撤销。

当前已有多格式导入/OCR核对、字段编辑、精确去重及导入保护；近似查重、集中质量问题清单和批量差异修复是下一阶段重点。

## 三、整理与检索

- 多级收藏夹、多重归属、标签、收藏/待核对/回收站；单题和多选拖放、批量归类；明确区分“追加归属”和“移动”。
- 全文、公式关键词及组合条件搜索；支持题型、知识点、难度、来源、教材、时间、使用记录、审核状态等筛选、排序和保存条件。
- 智能收藏夹根据条件自动聚合；跨库查找、最近使用、未使用题、缺答案题可直接进入。
- 搜索和分页应在数万题规模仍可用，不把完整题图/所有公式一次性加载到界面。

当前已有多级收藏夹、组合筛选、批量属性和拖入追加；保存搜索/智能收藏夹、公式等价检索及数据库全文索引尚未完成。

## 四、高效编辑与版本

- 就地编辑、完整编辑台、键盘操作、公式/表格/题图工具、模板；批量分值、题型、来源、标签和答案校正。
- 自动草稿、保存/取消、撤销/重做、版本比较、回滚；冲突时拒绝覆盖而不是最后一次保存静默获胜。
- 多选操作给出影响题数与预览；导入/OCR结果与教师手改分开保存，避免重新识别抹掉人工修改。

当前已有完整编辑、草稿、题目修订与来源保护；全字段可视差异、更多批量校对和工作流级撤销还可加强。

## 五、选题与组卷

- 手动选题篮、拖放、顺序调整、指定大题、新卷、快速替题、相似题对照；去重和重复使用提示。
- 按题型/分值/知识点覆盖/难度/预计时长建立组卷蓝图，缺题明确提示；支持随机抽题、约束组卷、同构A/B卷。
- 卷内题目固定版本，题库更新不自动改变已用试卷；人工比较后决定采用新版。
- 题卷、答题卡、答案解析、速对框、模板与排版参数；PDF、可编辑Word、源文件/项目备份均能离线导出。

当前已有手动组卷、来源快照、A/B选项乱序及多格式导出；蓝图约束组卷、智能替题和相似题推荐仍是规划。

## 六、审核与AI

- 草稿/待核对/可使用/有争议等状态、核对备注、修改证据、质量检查清单；可追溯是谁/何时/基于什么修改。
- AI辅助知识点、答案疑点、表述与条件核查、整卷配比和梯度评析；发送预算、隐私范围、取消、缓存、错误重试均由用户掌握。
- AI结论需保留原题ID、证据与不确定性；过期报告不能直接采用，不自动覆盖题干/答案/解析。
- 联网或团队版再增加复核人、评论、审批与权限，不把这些强加给单机用户。

当前已有待核对、版本、整卷AI定性分析、确认/缓存/后台/取消与元数据采用保护；完整审核流程尚未实施。

## 七、教学使用数据

- 记录选入哪些试卷、何时使用、重复率与覆盖变化，帮助避免反复抽到同一题。
- 如果将来导入真实学生作答，才计算正确率、难度、区分度、错选分布及易错知识点；显示样本量和统计前提。
- 没有作答数据时只显示已有标签和定性估计，不能编造信度、效度、班级水平或学习效果。

当前只有使用次数/最近使用和本地标签统计，不存在真实学生成绩系统。

## 八、数据安全与性能

- 离线可用、事务写入、损坏检测、版本迁移、自动/增量备份、恢复演练、跨设备可迁移备份；附件与题目同步恢复。
- 大型题库宜采用SQLite等数据库及全文索引，附件内容寻址去重；按需查询、缩略图缓存、后台索引与可取消批量任务。
- 预览虚拟化、分页几何缓存、稳定订阅和有界缓存；同时验证公式、长表格、几何图、续页、答题卡、打印，不用关闭动效或遗漏内容换速度。
- API Key本机安全存储；不上传题库或个人作答，除非用户明确授权。可选云同步应有冲突处理和数据导出退出路径。

当前题库仍是本机JSON与有界修订数量，不应宣传成十万题数据库。下一阶段应优先补自动备份/恢复和数据库索引迁移，而不是不断堆装饰或AI按钮。

## 推荐开发顺序

1. 稳定性底座：数据库与索引、自动备份/恢复、实际大题库性能与导出完整性。
2. 高频效率：集中质量核对、批量字段校正、相似查重、保存搜索/智能收藏夹。
3. 教学能力：教材知识树、组卷蓝图、替题与复用追踪。
4. 最后按真实需求加入学生作答统计、多人审核或可选同步，不默认建设云平台。

参考的是功能原则而非照搬代码：[Moodle题库](https://docs.moodle.org/503/en/Question_bank)的分类/版本/状态/使用记录，[Paperless-ngx](https://github.com/paperless-ngx/paperless-ngx/blob/dev/docs/usage.md)的检索与批量/版本，[Anki](https://github.com/ankitects/anki/blob/main/docs-site/manual/importing/text-files.mdx)的稳定身份及导入更新/去重取舍。
